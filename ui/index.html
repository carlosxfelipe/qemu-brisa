Framework Brisa
Tecnologia desktop que sustenta este aplicativo
Brisa Desktop Framework
O Brisa é um micro-framework desktop zero-dependências desenvolvido em Go por Carlos Felipe Araújo. Ele permite criar aplicações modernas combinando backend nativo tipado em Go com interfaces em HTML/CSS/JS, streaming de eventos via SSE, temas integrados e empacotamento standalone.
